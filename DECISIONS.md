# Decisions (ADR log, append-only)
Updated: 2026-10-12
ADR-01..64 live in `docs/design/bangalore_rpg_design_decisions_v1.md` (the "why" of the whole design). This file continues the numbering with decisions made **in the repo** during the build. Supersede, don't delete: add a new row "ADR-xx supersedes ADR-yy". Rows marked *(proposed)* await the user's yes/no at the next audit.

| ID | Date | Decision | Why | Rejected alternative |

| ADR-65 | 2026-10-11 | Design docs copied verbatim into `docs/design/`; root holds only the 5 working docs + `AUDIT_LOG.md` | `project_docs_convention.md`: reference, don't copy; settled docs are never rewritten | Pasting design content into root docs |
| ADR-66 | 2026-10-11 | Content and assets stay under `src/` (`src/data/**`, `src/assets/{tilemaps,tilesets,sprites}`), discovered by `import.meta.glob`. The design docs' root paths (`data/`, `maps/`, `assets/`) map 1:1 onto these | Bundler-resolved URLs work standalone and when the game is consumed as a library; validators and loaders already wired; zero churn before P1 art | Moving to root `data/`+`maps/` (breaks `?url` imports, large rename for no runtime gain) |
| ADR-67 | 2026-10-11 | Tiled layer taxonomy stays `Ground → Walls → Objects → Collision → Above Player → Effects → Foreground` (`maps.manifest.json#layerOrder`), plus object layers `Spawns`, `Objects Layer`. Design-doc names map onto it: ground=Ground, ground_detail+props_below=Walls/Objects, props_above=Above Player, npc_spawn=Spawns; `pulse_slots` added as an object layer when City Pulse lands | `WorldScene` reads `layerOrder` from the manifest, so a rename is a data edit later, not a code change; both existing maps + generator + validator already use this | Renaming now, before P1 replaces the maps anyway |
| ADR-68 | 2026-10-11 | Package/app name stays `Bangalore Times` until the title decision (unfinished_business "Game title"); docs use the working title NAMMA OUTBREAK | Renaming package, PWA manifest, save key and HUD twice is waste | Renaming to Namma Outbreak now |
| ADR-69 | 2026-10-11 | One `WorldScene` renders every place from a `districts.json` entry; `AirportScene`/`WhitefieldScene` deleted. Saves persist `{districtId, x, y}` (v1.2.0) with migrations from 1.0.0/1.1.0 scene names | Tech architecture §0/§7 steps 1–4; kills the `PGScene` dead-end class of bug; a save survives any change to how a place is drawn | Third hand-written scene; persisting scene keys |
| ADR-70 | 2026-10-11 | Every area edge goes through `TransitScene` (fade-to-black; ride card for bus/metro/cab/scooter, plain fade for walk), driven by the exit's data | Design system §7 motion rule once, not per scene; later rides (window parallax, hotel nights, office time-lapse) extend it without touching WorldScene | Per-exit transition code |
| ADR-71 | 2026-10-11 | Exits are zones first: `zone:reached` is emitted before the destination's `unlock` rule is checked; district gating = `unlock{quest, reputation, flags}` evaluated by `ReputationManager.canEnter`; quests set generic `on_complete.set_flags` (the `unlock_scene` field is retired and rejected by the validator) | The arrival quest's last objective is "reach the exit"; emitting first lets the quest complete and open the gate in one step. Flags are the one unlock currency for districts, dialogue and phone apps | Separate "exit" and "trigger" zones; quests naming scenes |
| ADR-72 | 2026-10-11 | Only `TitleScene › Continue` restores a save; `WorldScene` never hydrates from disk. Autosave on district entry and on scene shutdown | The old scenes called `restore()` in `create()`, so New Game silently inherited the previous run's stats; entry autosave means closing during a transit card resumes at the arrival, not on the exit zone (ADR-63 "autosave on area transition") | Restore-on-create |
| ADR-73 | 2026-10-11 | Ambient crowds, NPC placement and data-placed objects are district data (`ambient`, `npcs`, `objects`); behaviours are named molecules in `src/world/behaviours/` (`BEHAVIOUR_NAMES` kept Phaser-free so the validator can import it) | Atomic architecture: district references ids, never inline copies; adding a mechanic = one molecule + a name in data | Per-scene bot/NPC code |
| ADR-74 | 2026-10-11 | Validators have two channels: **problems** fail the build (anything the engine would mis-load or the player could never reach), **warnings** print and pass (design nits: door not 32×48, ADR-40 density). `validateWorld` cross-checks districts against maps and walks exits from `START_DISTRICT` | A renamed spawn or an unreachable district is silent at runtime; a mis-sized door is a Tiled fix, not a broken build | Everything fatal (blocks P1 art iteration) / everything advisory (dead ends ship) |
| ADR-75 | 2026-10-11 | Capacitor **8.5.3** pinned exact (core/cli/android/ios); iOS shell generated with **Swift Package Manager** (`cap add ios --packagemanager SPM`) so no CocoaPods is needed; `appId` placeholder `com.bangaloretimes.app` until the title decision; `@capacitor/*` plugins are declared in the phase whose molecule uses them (P3 preferences/filesystem, P6 haptics/app/status-bar, P9 share), not up front | Smallest shells that build; SPM is Capacitor's supported path and sidesteps the missing `pod` on this Mac; appId becomes permanent only at M1; unused plugins are unused licences | Install all nine plugins now; CocoaPods |
| ADR-76 | 2026-10-11 | Platform boundary is enforced by `scripts/validate-platform.mjs` in `pnpm validate`/`build`: `navigator.*`, `localStorage`, `sessionStorage`, `indexedDB`, `@capacitor/*`, `Capacitor.*` are build errors outside `src/platform/`; an explicit `ALLOWLIST` names the task that removes each exception (today: `SaveManager` → T-011) | Mobile foundation §4 asks for a lint; a 60-line grep with tests is cheaper than an ESLint setup and fails the build the same way | ESLint plugin; a rule nobody runs |
| ADR-77 | 2026-10-12 | **Title: Bangalore Times** (supersedes ADR-68). Package `bangalore-times`, PWA name, title screen, save key `bangalore-times:save`, Capacitor `com.bangaloretimes.app` / "Bangalore Times". "NAMMA OUTBREAK" remains only as the historical working title inside `docs/design/` | User decision at the P0 audit; the React shell was already `BangaloreTimes` | Namma Quest / Namma Outbreak |
| ADR-78 | 2026-10-12 | ADR-66, ADR-67 and ADR-75 confirmed as built — the user delegated these engineering calls ("if anything better is there you can make it") | Audit rule: delegated engineering calls are decided and recorded, not re-asked | Re-opening at every audit |
| ADR-79 | 2026-10-12 | P1 style reference generated with Figma AI image generation (user's personal team plan, never the employer org), recorded in `src/assets/_meta/style.json` with prompt/model; palette extraction is in-repo (`scripts/extract-palette.mjs` + `scripts/art/quantize.mjs` median-cut, no dither) because sharp's quantiser caps at 16 colours. The user's reference images stay out of the repo (third-party art) and are described, not copied | Retro Diffusion / PixelLab have no API access here yet; the style lock needs an image and a palette now, and the quantiser is needed by the whole pipeline regardless | Hand-coding the scene in the procedural generator (slow, weaker); committing third-party references |
| ADR-80 | 2026-10-12 | Character creation adds a **skin tone** field (5 swatches, `c.skin.1..5`) beside name/gender/age/hometown/college/degree. Sprite = gender × skin × age band (≤23 fresher: backpack/sling; 24+: laptop/tote). No other customisation | The docs' "age + gender assign the sprite" needs a skin tone from somewhere; deriving it from hometown would be a regional stereotype. Skin is identity, not cosmetics, so it is asked once | Infer from hometown; a single default tone |
| ADR-81 | 2026-10-12 | Player and citizen sprites come from the in-repo rig v2 (`scripts/art/character.mjs`), chibi proportions per the user's references, every colour a token on `palette.gpl`, 20 player + 8 citizen sheets generated by `pnpm art`. PixelLab stays the planned tool for hero NPC sheets once an API key exists | Grid-perfect, palette-locked by construction, reproducible, 1–2 KB per sheet; AI image models cannot produce frame-aligned 32×48 sheets; no PixelLab access yet | PixelLab now; hand-drawn sheets |
| ADR-82 | 2026-10-12 | Colour tokens are generated: `scripts/art/tokens.mjs` (name → palette index) → `src/assets/_meta/tokens.json` → `src/ui/tokens.ts` (`hex()`, `color()`). Sprite sheets must be 128×192 and on-palette (build error); tilesets off-palette are warnings until regenerated (T-021) | ADR-61 enforced by the validator, not by review; one source of truth for art scripts and runtime | Raw hex in scenes; tokens typed by hand twice |
| ADR-83 | 2026-10-12 | Text entry in Phaser forms goes through one hidden DOM `<input>` (focused when a text row is active) so phones get their on-screen keyboard; navigation stays on Phaser keys/taps | Mobile foundation §6 P1–P2 gate: "form usable with on-screen keyboard on phone"; Phaser has no native text input | Phaser DOM plugin (needs `dom.createContainer`, heavier); desktop-only keystrokes |
| ADR-84 | 2026-10-12 | **Supersedes ADR-81.** Player sprites are generated in the reference style (Figma AI, same model as the style lock, prompt template in `src/assets/_raw/characters/prompt-template.md`) and imported by `scripts/import-sheet.mjs`: chroma-key → 3×4 cell split → bottom-align to the 32×48 baseline → quantise to `palette.gpl` → pack 4×4 → remap skin onto the five `c.skin` ramps. Raws live in `src/assets/_raw/characters/` and `pnpm art` reproduces the sheets from them. The code rig (`character.mjs`) is demoted to citizens/placeholders until they go through the same pipeline (T-022) | P2 audit: the rig was "not at all like the screenshots". The import pipeline is what art_pipeline §5 always specified; one generation yields all five tones | Keeping the rig; hand-pixelling |
| ADR-85 | 2026-10-12 | Amends ADR-80: sprite = gender × skin only (`player_<m|f>_<1..5>`); age-band bag/attire variants are deferred to attire layers (T-022). Age still drives dialogue flavour | One raw per base; attire layers need a compositing step the pipeline does not have yet | 20 raws (10 credits per base) |
