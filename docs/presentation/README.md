# Bangalore Times — the presentation

`Bangalore-Times-Presentation.html` is a single self-contained file (2 MB): every map, sprite and image is embedded, so it opens offline in any browser (fonts load from Google Fonts when online, with system fallbacks). Arrow keys or PageUp/PageDown move a slide; it also scrolls as one page and follows light/dark mode.
